## New

- **Benchmark of the streaming settings.** Each host can be benchmarked to find the streaming settings that suit it.
- **4:4:4 video on the client.** Full-chroma 4:4:4 video packed into 4:2:0 frames is now rebuilt on the client, completing the protocol support.
- **Roaming on the client.** The running stream follows a change of network instead of dropping.
- **Resolution change during a stream.** The stream resolution can be changed while it is running, on a host that supports it.
- **Stream resumes after another app covers it.** When Home, a system prompt or the screen turning off stops the stream, coming back rejoins the same game session instead of ending it. It resumes at most 3 times in 2 minutes, so a prompt that keeps coming back cannot loop.
- **Trigger dead zone.** The triggers have a 2% rest zone, adjustable in the settings.
- **Keyboard captured by the stream window.** On Android 16.1+ the stream window captures the keyboard itself, so the accessibility service is gone. Older devices keep the Samsung meta-key fallback.
- **Display luminance sent to the host.** With HDR on and a host that supports it, the screen's minimum, peak and average brightness are sent when a game starts or resumes, estimated when the peak is missing, with an optional manual peak in the settings.
- **10-bit colour in SDR.** A new option streams SDR in 10-bit colour to reduce banding.
- **Frame rate warning.** You are warned when the stream frame rate doesn't divide the screen refresh rate.
- **Keep the GPU busy with PyroWave.** A new optional setting keeps the GPU busy between one decode and the next.
- **Staged exit from an HDR stream on Android TV.** Leaving an HDR stream on Android TV is done in steps.
- **Snapdragon decoder extras.** Extra Snapdragon decoder keys are used only when the decoder declares them.
- **Network stalls covered by Opus concealment.** Audio stalls are masked by Opus packet-loss concealment instead of the buffer.
- **The stream ends with a reason.** When the decoder doesn't recover, the stream ends and tells you why.
- **Handhelds.** New option to swap View and the touchpad click, and a "device held upright" option for the device's motion sensors.
- **DSCP marking.** Audio and video packets are marked DSCP (EF and AF41) so networks that honour it can prioritise them.

## Fixes

- **Audio route changes.** When headphones, Bluetooth or a USB DAC connect or disconnect, AAudio is reopened on the new route instead of staying on AudioTrack for the rest of the stream.
- **Closing the stream.** The screen no longer freezes waiting for the video decoder to reset when the stream ends.
- **Print Screen.** The key is sent with the Windows VK_SNAPSHOT code.
- **Late packets.** Frames are no longer dropped because of a late packet when the stream has no parity.
- **Controller LED.** The RGB LED colour is set on a background thread, which avoids crashes and ANRs.
- **H.264 decoding.** SPS patches are applied only on Android below 8, and the video surface's producer throttling is turned off on the newest Android.
- **Telemetry views update at the next stream.** A view published again is picked up when the next stream starts, instead of up to a day later.

## Notes

- Adaptive bitrate needs a Vibepollo host, host-side captures a Scirocco host, and 4:4:4, resolution change, display luminance and network-change following a host that supports them; on any other host nothing changes.

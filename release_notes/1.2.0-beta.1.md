## New

- **Benchmark of the streaming settings.** Each host can be benchmarked to find the streaming settings that suit it.
- **4:4:4 video on the client.** Full-chroma 4:4:4 video packed into 4:2:0 frames is now rebuilt on the client, completing the protocol support.
- **Roaming on the client.** The running stream follows a change of network instead of dropping.
- **Frame rate warning.** You are warned when the stream frame rate doesn't divide the screen refresh rate.
- **Keep the GPU busy with PyroWave.** A new optional setting keeps the GPU busy between one decode and the next.
- **Staged exit from an HDR stream on Android TV.** Leaving an HDR stream on Android TV is done in steps.
- **Snapdragon decoder extras.** Extra Snapdragon decoder keys are used only when the decoder declares them.
- **Network stalls covered by Opus concealment.** Audio stalls are masked by Opus packet-loss concealment instead of the buffer.
- **The stream ends with a reason.** When the decoder doesn't recover, the stream ends and tells you why.
- **Handhelds.** New option to swap View and the touchpad click, and a "device held upright" option for the device's motion sensors.
- **DSCP marking.** Audio and video packets are marked DSCP (EF and AF41) so networks that honour it can prioritise them.

## Fixes

- **Print Screen.** The key is sent with the Windows VK_SNAPSHOT code.

## Notes

- Adaptive bitrate needs a Vibepollo host, host-side captures a Scirocco host, and 4:4:4 and network-change following a host that supports them; on any other host nothing changes.
